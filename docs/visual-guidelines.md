## Typography

- Primary direction: COSKY Serif
- Web fallback: Georgia / Times New Roman
- Secondary: Inter / system sans-serif

The current repository does not include the COSKY Serif font file. Add the licensed font under `assets/fonts/` before using it in production.

## Motion

Use slow, subtle motion. The ribbon pattern should feel fluid and ordered, not decorative-heavy.

Preferred motion:

- Slow ribbon float
- Light reveal on scroll
- Header blur after scroll

Avoid:

- Dense particle backgrounds
- Heavy page transitions
- Animation that blocks reading or form submission
